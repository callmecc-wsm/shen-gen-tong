## 二、功能优先级

### 🔴 P0 - 模板案例库系统（立即做）

**核心价值**：通过真实案例图片和说明，让用户直观理解材料标准

**两种模板类型**：

1. **外部官方模板**
   - 例如：VFS申请表、保险购买页面
   - 交互：点击链接 → 跳转外部下载
   - 技术：简单的外部链接

2. **内部案例模板**（重点）
   - 例如：真实的行程单案例、银行流水样本、在职证明示例
   - 交互：点击链接 → 侧拉窗展开 → 查看图片+说明
   - 技术：Drawer组件 + 图片展示

**具体案例内容举例**：

| 模板名称 | 包含内容 | 所在步骤 |
|---------|---------|---------|
| 行程单真实案例 | 3-5张真实行程单截图 + 制作要点说明 | 步骤5 |
| 银行流水样本 | 合格流水示例 + 标注关键项（余额、日期） | 步骤6 |
| 在职证明示例 | 中英双语模板 + 填写要点 | 步骤6 |
| 申请表填写指南 | 逐页截图 + 每个字段的填写说明 | 步骤4 |
| 酒店预订单样本 | Booking可取消订单截图 + 注意事项 | 步骤5 |

**交互设计**：

```
正文内容中插入：
"不知道行程单该怎么做？[查看真实案例]"

用户点击 [查看真实案例] →
  侧拉窗从右侧滑出（PC端占屏幕40%，移动端占80%）→
  显示内容：
    - 标题：行程单真实案例
    - 3张图片（可切换查看）
    - Markdown文字说明：
      * 行程单需要包含哪些信息
      * 格式要求
      * 常见错误
```

**数据结构**：

```json
{
  "templates": [
    {
      "id": "itinerary-sample",
      "title": "行程单真实案例",
      "type": "internal",
      "category": "行程与预订",
      "images": [
        "/templates/images/itinerary-1.jpg",
        "/templates/images/itinerary-2.jpg",
        "/templates/images/itinerary-3.jpg"
      ],
      "description": "# 行程单制作要点\n\n## 必须包含的信息\n- 日期、城市、酒店名称...",
      "relatedSteps": [5]
    }
  ]
}
```

**后台维护方式**：
- 配置文件：`/public/templates/config.json`
- 图片存放：`/public/templates/images/`
- 更新流程：修改JSON + 替换图片 → 重新部署

### 🟡 P1 - 文档生成功能（后端部署后做）

**核心价值**：用户填写信息 → 自动生成符合要求的文档

**第一期功能**：

1. **行程单生成器**
   - 用户输入：
     * 出发/返回日期
     * 每天的城市、酒店名称
     * （可选）交通方式
   - 系统输出：
     * 标准格式的Excel行程单
     * 或PDF格式（带表格）
   - 技术方案：前端表单 + SheetJS导出Excel / jsPDF导出PDF

2. **在职证明生成器**（可选）
   - 用户输入：
     * 公司名称、职位、入职日期
     * 月薪、旅行日期
   - 系统输出：
     * 中英双语Word文档
   - 技术方案：模板填充 + Docx.js

**暂缓原因**：复杂度较高，需要先验证用户对案例库的反馈

---

### ⚪ 暂不考虑的功能

以下功能暂不开发（优先级低或不符合产品定位）：

- ❌ **个性化筛选**（已婚/未婚等）- 优先级低，用户可自行浏览相关内容
- ❌ **决策辅助工具**（时间计算器等）- 使用场景有限
- ❌ **AI材料审核** - 成本高，不符合产品定位
- ❌ **紧迫感提醒**（邮件/微信通知）- 暂无需求
- ❌ **用户社区** - 暂不开发UGC功能

## 五、技术要点

### 前端组件
1. **Drawer组件**
   - 使用React Portal实现
   - 支持响应式（PC端40%宽度，移动端80%）
   - 包含图片轮播和Markdown渲染

2. **模板链接解析**
   - 在Markdown中识别特殊语法，如：`[模板:itinerary-sample]`
   - 渲染为可点击的链接
   - 点击时触发Drawer打开

3. **图片管理**
   - 使用Next.js Image组件优化加载
   - 支持图片预览和缩放
   - 懒加载提升性能
